# 本地模型与数据路线

本项目运行、训练与推理不需要API或云服务。使用Python和NumPy即可在CPU上训练任务专用小网络；已有独立训练权重，游戏实际加载，不用规则AI冒充模型。

|模型|参数|输入与学习任务|边界|
|---|---:|---|---|
|C1|193|当方经典棋盘的10维公开特征，回归实际揭格反馈|9×9训练，中级/专家属分布外；单次反馈不是雷概率标签|
|L3|2017|共享棋盘、风险路径、生命、对手与近期位置共40维，监督模仿B3并在训练图纠偏|人工设计特征和教师策略；不等于自由强化学习|
|E|8|公开手工特征的参数搜索，以对局结果反馈|策略族内自主探索；现有实验未发现稳定优势|

开源本地语言模型可以另作文字解释或研究对照，但不是这类结构化状态决策的必要组成。下载语言模型不会自动给它扫雷能力，还需要合法观察接口、动作约束、训练数据和独立评测。本轮没有下载、部署或调用外部大模型，避免把部署一个现成聊天模型误称为自己的训练成果。

最终交付是可玩游戏、公开观察数据、可复核训练程序、真实权重与课程文档。小模型是其中可验证的技术产物。C1测试通关88/96，R1为96/96；L3对B2中级8/24胜、专家16/24胜，样本各6张基础图，没有普遍超过启发式的证据。

持续改进应保留完整失败、平局、超时和采集策略版本，按基础地图冻结分区。只有实际点击得到的反馈可作C1标签；L3教师动作只是模仿目标，不是最优解。训练集新增探索数据与留出测试严格分开，不能反复按测试表现调权重。详细字段与复现见[经典竞速](classic_race.md)、[生存模型](survival_v3.md)。
