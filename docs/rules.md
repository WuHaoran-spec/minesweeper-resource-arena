# 规则冻结：arena-v1.0

此页保留原始 9×9 实验协议。大棋盘挑战使用单独的 [arena-v2.0 规则](rules_v2.md)，两版结果不能合并。

本项目是扫雷的双人公开资源争夺变体。规则版本在实验前冻结，以下参数属于本项目工程设定，不表示经典扫雷规则，也不表示教师逐项指定的参数。机器可读配置见 `config/rules_v1.json`，权威实现见 `arena/env.py`。

## 地图与公开信息

棋盘为 9×9，固定 10 颗雷、3 个等价钻石。两起点为 (0,0)、(8,8)，坐标从 0 开始。先从其余 79 格均匀选择 3 个互不重复的钻石位置，再从排除起点和钻石的 76 格均匀选择 10 颗雷。地图不按可达性、胜率或观感筛选；生成后永不移雷。座位交换只交换玩家起点身份，先手参数只改变初始行动者，均不改变基础地图。

双方可见双方位置、分数、生存状态、剩余钻石、全部已揭线索、步数和行动者。起点立即揭示八邻域雷数；钻石位置公开且安全，但在到达之前不揭数字。起点、全部初始钻石、已揭安全格均进入 `known_safe`，被领取的钻石格仍保持已知安全。其余安全格到达时揭数，首版不自动展开零区。

策略只接收 `observe()`。隐藏雷位、生成种子、将来结果及其他策略内部状态不在观察中。公开对局编号为独立随机 ID，不编码地图种子。环境私有快照用于可信后端分支，禁止发给策略或浏览器。公开回放包含公开观察和动作，不包含私有快照。

## 行动、淘汰与终局

行动为 `up/down/left/right/wait`。移动上下左右一格，不允许斜行或远程取资源；等待同样消耗 1 步。轮流行动，淘汰者以后跳过；仅余一人生存时由其连续行动。默认最多 200 次总行动，并非每位玩家各 200 次。

合法动作只依据边界及公开已爆雷格计算。未知雷仍是合法目的格，不能利用后台真值剔除。双方可穿过或共占安全位置，不互相阻挡。钻石须实际到达才领取，先到者获得 1 分后钻石删除，不重复计分。踩雷者永久淘汰，雷公开但不删除，已得分数保留。

钻石全部取完、无人存活或达到步数上限时终局；同一步若同时满足多个条件，原因按此前顺序记录。胜负只比较钻石数量，同分记 `draw`。存活状态、揭格面积、速度和策略说明不参与胜负。主模式的 `wait` 始终允许，无法移动时可以等待到上限，因而不存在死循环或需要偷偷重置地图的情况。

非法动作抛出错误且不改变步数、版本或棋盘；终局不再接受动作。暂停是界面调度状态，不是棋盘动作，也不消耗步数。重置产生新的对局 ID 并清空动作历史；界面请求须带当前对局 ID 与版本号，后端拒绝旧请求。经典旗标是标记，不能作为推断器的雷位真值；主模式不提供把任意旗标变成事实的接口。

## 与经典模式的区别

经典模式使用相同八邻域数字含义、固定雷数、揭格、旗标和零区展开，揭开全部 71 个安全格获胜，踩雷失败；其雷位在生成时固定，不承诺首点安全。旗标可添加或移除，已揭格不能插旗，已插旗格须先去旗才可揭开。主模式增加双人、角色位置、逐格移动、共享线索和公开安全资源，关闭零区展开，以钻石计分，踩雷只淘汰行动者。

## 规则检查与决策记录

1. **相邻钻石**：钻石可能在起点附近，甚至一步可取。这是未筛选均匀分布的合法样本，不暗中移远。两起点分布对称，但单图不保证公平；评测交换座位和先手。
2. **先手优势**：距离相等的竞争可能被先手打破。这是轮流规则的特性，不宣称已消除；同一基础地图包含两座位×两先手条件。
3. **领先后淘汰或等待**：终局仅按得分，领先者淘汰仍可能获胜。此规则允许风险选择，不能因为与预期不符而删局。故意等待也可能合理，但不会冻结对手；上限结算按实际得分。
4. **不可达资源**：可能出现雷阻断和超时，完整保留。等待让受困者仍能完成有限步对局。
5. **公开爆雷阻行**：最小明确化是禁止进入已公开爆雷格，只使用公开信息。未知雷仍允许进入。此决定冻结在 v1.0，不按比赛结果调整。
6. **固定起点**：采用对角起点以消除起点重合歧义；身份和先手独立交换。钻石数为奇数不排除平局，因为未取得资源可留在地图上。

上述现象属于规则允许行为或需量化的效应，并不自动构成程序错误或学习成功。任何今后改变须更新规则版本并重新训练、评测，不能合并为同一规则结果。

## 核验

`python -m unittest discover -s tests -p "test_env.py" -v` 检查雷数、线索、安全条件、身份交换、领取唯一性、淘汰后继续、得分结算、200 步上限、隐藏信息与动作掩码、非法输入原子性、共享位置、零区差异、公开回放、私有分支一致性、重置以及 100 个地图的随机合法行动。私有真值只在规则测试中用于核验，不作为策略输入。构造测试地图明确属于测试夹具，不进入训练或正式评测。
