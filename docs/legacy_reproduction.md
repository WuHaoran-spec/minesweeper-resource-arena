# 原始9×9实验的代码与数据

原始v1实验的完整源代码与产物对应发布标签 `arena-v1.0-experiment`。该历史树在新增大棋盘和探索实验前已完整审计；`data/source_provenance_v1.json`保留其文件哈希。新版本仍保留原始默认环境与模型行为，已经用更新后的v1审计入口重新核验5200正式局和860训练相关轨迹。

`main`包含大棋盘v2与E自主参数搜索。v1、L2和E各有自己的数据目录、规则/方法协议与审计入口；不能把旧版成绩称作新版成绩。模型权重也不可互相冒充。

GitHub采用Git Database API发布：远端历史保留审计过的MIT许可根、原始v1树和最新版本树。API生成提交的元数据与本地审计提交不同，但相应树及每个文件的Git对象哈希逐个比较一致。本地审计bundle用于保留本机完整工作记录；远端提交SHA以GitHub和私人发布记录为准。
