# 实现结构与技术步骤

S101 初始化固定地图 → S102 构造公开观察 → S103 风险推断 → S104 资源与对手决策 → S105 公共规则校验与状态更新 → S106 记录反馈并判断终局。未终局回到S102。

| 步骤 | 模块 | 对应约束 |
|---|---|---|
| S101 | arena/env.py, config/rules_v1.json | 起点/钻石安全，其他格均匀放固定数量雷；不筛图 |
| S102 | Arena.observe/legal_actions | 不含seed、隐藏雷图、对手内部状态；未知真值不影响mask |
| S103 | arena/risk.py | 确定约束、连通分量计数、全局余雷组合加权；预算不足显式近似 |
| S104 | arena/policies.py | B0随机，B1风险路径，B2对手竞争代价，L真实MLP动作评分 |
| S105 | Arena.step, arena/server.py | 四邻移动/等待、唯一计分、淘汰跳过、200总步；epoch和revision防旧请求 |
| S106 | save_replay, arena/experiment.py | 公共逐步记录，私有快照隔离；每局重放一致性验证 |
| S201 | arena/learning.py | 按基础地图固定训练/验证/测试划分，教师动作标签和真实优化 |
| S202 | arena/experiment.py | 换座/先后手，保留失败/平局/超时；地图分组bootstrap |
| S203 | arena/learning.py refine | 仅挖掘训练集失败/分歧，再补训一次并独立复测 |

前端不持有雷图，不实现另一套游戏规则；它只发送人工动作、AI推进命令，绘制服务返回的观察。服务默认仅127.0.0.1，拒绝异源POST并检查Host。所有策略只接收公开字典，没有环境对象引用。

确定事实、概率后验和启发式代价分别表示。模型输出为行动分数，不生成心理叙述。路径风险成本是启发式；没有把多个格子的边缘安全概率相乘当作精确路径成功率。

本系统实现的是仿真游戏环境中的有限信息决策。共享公共线索和公共目标是环境设计；概率计数、监督学习及软件接口是已知技术的组合实现，未证明新颖性或任何真实工业迁移效果。
