# 实现结构与技术步骤

初始化固定地图后，S101 构造公开观察 → S102 风险推断 → S103 构造资源与对手特征 → S104 选择动作 → S105 校验 → S106 执行与结算 → S107 记录 → S108 判断终局。未终局回到S101。编号与附图2及课程说明书一致。

| 步骤 | 模块 | 对应约束 |
|---|---|---|
| 初始化 | arena/env.py, arena/config.py | 公开安全条件外均匀放固定数量雷；保留V1，V2独立配置，不筛图 |
| S101 | Arena.observe/legal_actions | 不含seed、隐藏雷图、对手内部状态；未知真值不影响mask |
| S102 | arena/risk.py | 确定约束、连通分量计数、全局余雷组合加权；预算不足显式近似 |
| S103/S104 | arena/policies.py | B0随机，B1风险路径，B2对手竞争代价，L/L_v2真实MLP动作评分 |
| S105 | arena/server.py | epoch和revision防旧请求；核对控制者与合法动作 |
| S106/S108 | Arena.step | 四邻移动/等待、唯一计分、生命/淘汰、版本对应上限和终局 |
| S107 | save_replay, arena/experiment.py | 公共逐步记录，私有快照隔离；每局重放一致性验证 |
| S201 | arena/learning.py | 按基础地图固定训练/验证/测试划分，教师动作标签和真实优化 |
| S202 | arena/experiment.py | 换座/先后手，保留失败/平局/超时；地图分组bootstrap |
| S203 | arena/learning.py refine | 仅挖掘训练集失败/分歧，再补训一次并独立复测 |

前端不持有雷图，不实现另一套游戏规则；它只发送人工动作、AI推进命令，绘制服务返回的观察。服务默认仅127.0.0.1，拒绝异源POST并检查Host。所有策略只接收公开字典，没有环境对象引用。

## V2大棋盘扩展

`arena/config.py`保存版本预设：V1为9×9/10雷/3资源/1生命/200步；V2中级为16×16/40雷/7资源/3生命/800步，高级为30列×16行/99雷/11资源/3生命/1600步。矩形棋盘使用独立width/height，不能把兼容字段size当作总行数。V2公开双方角落3×3安全区并展开零区，资源只在实际到达时计分；踩雷扣生命，仍存活即回原出生点，公共线索和分数保留。完整规则见[rules.md](rules.md)。

`policies.prepare_v2`构造32维公开动作特征，规则策略遍历全部资源，网络只接收启发式预选的三个资源槽。V2专用网络为32→48→1，共1633参数，读取`challenge_final.npz`；V1的27→32→1权重继续保留。`arena/challenge_training.py`独立完成采集、初训、训练图纠正、留出对战和重建核验，使用`data/challenge_v2`及仓库外`challenge_manifest.json`，不覆盖V1数据。

`arena/classic.py`单独实现经典三档难度、首击格与邻格安全、旗标、零区和按旗数连开；它不是主模式的另一个计分接口。经典终局允许显示雷以便玩家复盘，主模式观察仍不暴露隐藏雷图。

## 无教师探索与模仿基线分离

`arena/exploration.py`在同一V2中级环境内搜索八维线性动作评分系数，使用完整对局结果，不用教师动作标签。`E`读取`models/exploration_final.npz`，与`L_v2`模型分开。其私有地图清单、公开协议、搜索、验证、独立确认与行为日志位于独立路径；只有可信运行器持有生成种子，策略仍只收到公共观察。发现阶段的候选行为不能代替独立测试确认。具体策略族、目标和边界见[algorithms.md](algorithms.md)。

确定事实、概率后验和启发式代价分别表示。模型输出为行动分数，不生成心理叙述。路径风险成本是启发式；没有把多个格子的边缘安全概率相乘当作精确路径成功率。

本系统实现的是仿真游戏环境中的有限信息决策。共享公共线索和公共目标是环境设计；概率计数、监督学习及软件接口是已知技术的组合实现，未证明新颖性或任何真实工业迁移效果。
