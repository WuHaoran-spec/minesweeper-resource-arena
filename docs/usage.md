# 安装与使用

已在 Windows 11、Python 3.12、NumPy 与本机浏览器上实际运行。其他系统有通用命令，但未宣称经过同等网页验收。

## 启动

安装 Python 3.10 或更新版本并加入 PATH。在本目录双击 `start.bat`；首次运行会安装 requirements.txt 中的 NumPy。也可执行：

```console
python -m pip install -r requirements.txt
python -m arena.server
```

打开 http://127.0.0.1:8765 。只绑定本机，不上传对局，不使用付费 API。若8765被占用，用 `python -m arena.server --port 8766`，相应更改浏览器地址。停止服务：运行窗口 Ctrl+C。

## 人机与双人游戏

选择共享棋盘，玩家 A 选“你”，B 选 B2 或 L，点击“新开一局”。L 读取 models/L_final.npz 的真实参数；文件缺失时报错，不回退冒充规则模型。两边都选人工即可本机双人轮流；两边选AI可观察完整自动对局。所有人共享同一张棋盘。

方向键或 WASD 移动，空格等待；也可点相邻方格或方向按钮。不能远程点击钻石、斜走或一次多走几格。右键只是做标记，标错不会欺骗概率求解器。轮次、淘汰、得分与剩余步数在棋盘上方显示。新开局会更换地图，不承诺无猜或钻石可达。

“暂停”停止自动和人工移动；“AI 单步”在暂停时让当前AI走一步，保持暂停。人工轮次需继续后操作。速度滑块只控制展示间隔，不改变轮次或正式评测预算。

风险热图只显示最近一次AI决策前基于公开信息计算的风险。明确标出 exact_global_model_count（完整全局计数）或 approximate_cutoff（计算预算不足的近似），不要把近似值当严格概率界。决策诊断中的规则目标是显式选择；学习模型的目标由动作解释推断，不是神经网络目标输出。实际 logits 可以核验。

经典模式可揭格、插旗、零区展开；揭完所有安全格获胜。首点也可能踩雷，不实现现代版本的首点保护或数字连开。不要将争夺模式规则误写成经典扫雷标准。

## 回放与分支

“导出本局 JSON”下载只含公开状态的回放；“回放刚导出的对局”或文件导入用于拖动逐帧查看。“保存局面”将完整环境保存在本机服务内存中，仅向界面给出不透明ID；“分支续玩”恢复该局面，并标为反事实重放。服务重启后内存快照失效。

公开回放不能推导所有未揭地雷，也不能用于独立恢复未知真值的互动分支。这是有意的信息隔离。离线可信研究程序可用 `private_snapshot`，但不得将快照传给策略或上传第三方。

普通界面交互标为“未经核验的交互”，不会自动计入真实玩家数据。浏览器测试使用 `?automation=1` 并标记 browser_automation。没有收集/公开真人训练数据；人工纠正动作的数据采集工作尚未开展。

## 训练与评测

```console
python -m unittest discover -s tests -v
python -m arena.learning initial
python -m arena.experiment initial
python -m arena.learning refine
python -m arena.experiment retest
```

具体子命令以 `python -m arena.learning --help` / `python -m arena.experiment --help` 为准。重训会替换同名权重和实验文件，若需保留本次交付，应先复制仓库。首次与复测地图、训练预算由 data/protocol.json 固定。实验报告只讨论已完成的运行。

模型体积很小，但CPU仍需做风险计数和路径计算；不是GPU深度强化学习。程序可能合法超时或输给B1/B2，这些记录不会删除。暂无在线联机、十人对战、真人数据训练、强化学习、自适应规则和真实排雷硬件。

## 本轮输入与回放补充

经典模式支持方向键/WASD移动光标、空格揭格、F旗标；主模式仍是移动角色。若文件选择器无法使用，展开“粘贴回放 JSON”，粘贴公开导出内容并载入。回放先校验坐标、数值和棋盘结构，损坏内容拒绝载入。文件选择器在本次自动化宿主中发生超时，粘贴入口已实际验证完整13帧及用户单帧附件。真人输入接口的自动化整局验收不是人类玩家数据。

新实验请优先使用[数据说明](data.md)中的隔离输出目录命令，保留交付模型和评测记录。
