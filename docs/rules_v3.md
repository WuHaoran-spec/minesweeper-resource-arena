# 生存效率计分版本 arena-v3.0

本版只用于16×16/40雷/7钻石或30×16/99雷/11钻石，每方3生命，分别800/1600总行动上限。地图生成、四邻移动、公共线索、踩雷复活和结束条件沿用v2；9×9原始实验仍使用v1。不会按策略表现筛选地图，也不改变已经固定的雷位。

玩家 i 的终局分为 `S_i = 100 G_i + 10 L_i − A_i/T`：G为取得钻石数，L为剩余生命，A为自己的行动次数（包含等待），T为整局行动上限。实现用整数 `T(100G_i+10L_i)−A_i` 比较，避免浮点误判平局。一颗钻石优先于最多3命及行动差；同钻石先比较命，同命再比较较少行动。这是明确公布的新胜负规则，旧成绩仍依旧规则保存。

一次实际行动的效用变化为 `100×本步取钻 − 10×本步损命 − 1/T`。它是已经发生的结果，不是精确概率或最优动作标签。UI动画间隔、暂停和设备速度不进入胜负，实际计算时间另外记录。提前死亡也会减少行动数，因此不能脱离钻石、生命和死亡解释效率。

规则计分和策略目标必须区分。B3/L3没有直接优化这条公式：B3在路径中加生命相关风险、近期重复与对手项；L3模仿B3的动作。它们可能为钻石冒险，领先方也仍可等待，规则不保证绝不冲雷或停滞。240场测试无一因次级分项改变按钻石计算的胜负，不能宣称这批实验已证明新计分改善比赛结果。详见[实测结果](survival_v3.md)。

观察新增公开的双方行动计数、最近24次实际位置、积分和规则标识；隐藏雷图、地图种子、未来结果仍只由环境保管。未知真雷不会使动作从合法集合中消失。快照和换座仍归属同一基础图，不能跨训练/验证/测试分区。

寻宝模式翻开的数字表示该格八邻域内地雷数，与经典语义相同；钻石及角色用独立小标记显示，避免遮住数字。钻石公开安全，不意味着周围没有雷。
