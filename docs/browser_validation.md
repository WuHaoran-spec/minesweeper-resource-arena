# 大棋盘版本浏览器验收（v2）

本节是实际本机浏览器操作，不是真人参与。测试地址为隔离的127.0.0.1本地服务，页面使用`?automation=1`；不涉及第三方游戏网站操作。

| 操作 | 实际核验 |
|---|---|
| 经典专家棋盘 | 30列×16行、480个可操作按钮、99雷、381安全格；首击后展开12安全格，未踩雷 |
| 鼠标与键盘 | 右键旗标计数99→98→99；方向键将光标从8行15列移至8行16列，空格触发数字连开检查 |
| AI对AI专家整局 | B1对B2，188次行动，A以10:1获胜；A余1生命，B耗尽生命；原因钻石取完 |
| 完整专家回放 | 导出公开记录，粘贴载入189帧，滑块0→188；比分、终局、480格保持一致 |
| 大棋盘局面分支 | 人工输入接口用键盘移动，再存局面；鼠标使第1步→第2步，分支恢复到第1步、480格、暂停、counterfactual_replay |

最终引擎重新启动后，L2实际载入最终权重，在专家盘149步以8:3战胜B2（A余1生命，B淘汰），记录为`expert_L2_B2_final_browser_replay.json`，截图`arena-expert-trained-v2.png`。E实际载入8参数最终文件，在中级盘98步以0:7负于B2，完整记录`E_B2_final_browser_replay.json`。浏览器点击导出JSON下载，再点回放，第1/98帧显示E八个真实系数和模型哈希`e9e266e71cd2a4d4b3782467d582e614e9cde98265145a248bf5b0c01780bdbe`。这些全部是UI验证局，未加入正式训练或评测。

较早的B1/B2界面测试是在闭包预算修订前的服务进程运行；新版重新启动后的149步模型局显示50,000比较预算，二者清楚区分。原始专家B1/B2完整轨迹：`docs/validation/expert_B1_B2_browser_replay.json`。截图：`docs/images/classic-expert-v2.png`和`arena-expert-complete-v2.png`。示例局不能替代正式留出评测。一个AI整局不证明整个难度分布均衡，按基础图统计见v2实验报告。

3MB回放在浏览器自动化宿主中首次点击超时，改用精确控件定位后完整载入并核验；文件选择器限制仍按下方记录披露。实际网页支持紧凑JSON导出、粘贴与文件导入，导入大小上限100MB。未录制视频，未采集真人数据。

# 本轮实际浏览器验收

2026-09-30，Windows、本机 Python 3.12.14 服务与 Codex 内置 Chromium。测试先在 8766 运行，再用独立的 8877 会话完成完整人工输入接口对局。全部操作为浏览器自动化；真人玩家数据仍为 0。截图来自实际运行，未生成假画面。训练使用的 Python 3.12.5 与此处浏览器服务运行时分开记录。

| 场景 | 本轮实际结果 |
|---|---|
| 键盘与鼠标输入 | 方向键实际执行角色移动；鼠标方向按钮执行一次人工输入并获得 L 的真实回应 |
| 人工输入接口对 B2 | 10 次键盘激活棋盘格输入，11 总步结束；A 胜、双方淘汰，保存完整公共回放 |
| 人工输入接口对 L | 7 次键盘激活棋盘格输入，17 总步结束；B 胜、钻石取完，保存完整公共回放 |
| 新权重 L 对 B2 | 从本次最终权重加载实际动作 logits；12 步、0:3，B 胜；保存完整 13 帧回放 |
| 暂停与 AI 单步 | 暂停状态下 1→2 步，B2 实际输出明确目标与精确计数状态 |
| 快照恢复 | 从第 3 步恢复到保存的第 2 步；来源变为 counterfactual_replay |
| 经典模式 | F 旗标添加/撤回；首格零区展开到 55 安全格，下一格到 56，之后踩雷终局；有真实截图 |
| 公开导出与重放 | 导出按钮创建公开 JSON；粘贴载入新 L/B2 对局，从 0/12 滑到 12/12，末帧仍 B 胜 |
| 用户附件 | 原附件只有第 5 步的一帧快照；粘贴载入成功，显示 counterfactual_replay。附件本身未公开 |
| 速度、热图、诊断 | Home 将间隔改为 80ms；热图显示公共线索风险，L 展示实际 logits 与事后推断目标 |
| 控制台 | 独立完整人机验收后 error/warn 列表为空 |

原生文件选择器在当前自动化宿主中超时，因此没有将本轮“原生文件选择导入”标为通过。已提供并实际验收“粘贴回放 JSON”入口，正常文件选择按钮仍保留。未录制视频；已提供可播放的真实逐步回放。没有完成手机、其他浏览器或真人可用性研究。

本轮修复：经典模式键盘光标/揭格/旗标；导入前完整坐标和状态校验；粘贴 JSON 入口；终局中文状态；回放载入等待当前动作结束。52 项 Python 单元与集成测试通过，Node 对合法回放及 11 种畸形输入检查通过。
