# 算法、输入与训练目标

## 公开观察与风险

`arena/risk.py` 只接收公开观察，不接收环境对象、种子或隐藏地图。起点、公开钻石和已到达安全格均作为安全条件；已爆雷为已知雷且不从总雷数中删除。经典八邻域数字形成约束。先做零/满约束及集合相减推理，再把约束前沿拆成连通组件。

对于组件的兼容雷分配，按组件雷数计数；合并各组件后，用 `C(U, M-k)` 加权剩余 U 个无约束格，其中 M 是扣除已知雷后的全局剩余雷数，k 是组件中的雷数。分母是全部兼容分配的加权和，分子额外要求被查询格为雷。这样精确结果符合“在非起点、非钻石格均匀放置固定10雷”的先验。没有筛选可达地图。

单组件超过23变量或深搜超过30000节点时，放弃此次完整模型计数，使用约束局部投影估计，明确标记 `approximate_cutoff`；其他完整计算标记 `exact_global_model_count`。近似值不是严格概率界限。已有24个4×4小盘与新增600个小图独立穷举对照测试；本次5200正式局实际出现97次近似标记，全部保留。

## B0、B1、B2

所有策略共享同一公开合法动作掩码。B0从合法动作中随机选择。未知雷不会因后台真值被屏蔽；已公开爆雷格按公开规则不可进入。

B1和B2都用Dijkstra计算到钻石的加性路线代价。进入格的代价为 `1 + 5p/max(0.03,1-p)`，已逻辑确认雷的格代价为10000。它是路径规划的启发式风险罚项，**不是路径存活概率**，没有把相关边缘安全概率相乘。等待额外加2的代价；没有暗改200步规则。

B1最小化行动后到某钻石的路线代价 d，不使用对手位置、分数和存活信息。B2对仍存活的对手计算公开位置到同一资源的代价 o，并使用：

`cost = d + 0.7 max(0, d-o+0.5) - 1/(1+|d-o|)`

选择最小代价的动作和目标。对手已淘汰时竞争项为0。该式是本项目工程启发式，表达距离竞争，不声称准确预测对手内部目标，也未证明最优。

## L与匹配消融

每个动作编码27个特征：目的格风险、是否已揭、是否等待、分数差、已用步数比例、资源数量、对手存活、目的格行列坐标（9项）；按坐标排序的最多3个资源各有动作后代价、当前代价、代价改善、对手到达代价、到达差、目的地是否为该钻石（每资源6项）。缺资源槽有明确占位值。

共享动作评分网络为 `fθ(x)=w₂ᵀ tanh(W₁x+b₁)+b₂`，隐藏宽度32，共929个参数。对五个动作的实际网络输出应用合法动作掩码，然后取最大logit。网页显示实际logit，不把启发式回退冒充学习；缺少权重直接报错。网络没有独立目标头，显示目标是动作后的路径归因，明确标注为**推断目标**。

训练是B2教师动作的监督模仿，损失为合法动作softmax交叉熵：

`J(θ) = -(1/N) Σ log softmax(mask(fθ(x_s,a)))[a_B2(s)]`

没有强化学习、奖励塑形或最优动作标签；终局胜负只是后续评测和训练图失败状态筛选依据。一次真实雷位也没有作为概率标签。Adam学习率0.002，batch256，初训45轮；从L_initial在训练图的输局状态和与B2动作分歧状态收集一次纠正数据，再对原样本与纠正样本合并训练20轮。每阶段固定预算内按验证集交叉熵最低保存检查点；不得用测试胜率挑权重。补训仍是监督学习，不声称自主发现策略。

`L_no_opponent`使用相同样本、标签、网络宽度、训练种子和45+20轮预算，移除**显式对手位置、得分和存活特征**：分数输入改为己方分数，对手距离、到达差及存活输入置零。共享已揭线索仍保留，因而仍可能反映双方过去行动的公共结果；不能称“排除对手造成的一切信息”。扰动对手位置、分数和存活后，其特征保持一致的测试已通过。

实现对应：S1观察与合法动作→`env.py`；S2约束风险→`risk.py`；S3动作/资源特征→`policies.prepare`；S4规则/网络评分→`policies.choose`；S5记录→`env.step`；S6模仿和补训→`learning.py`；S7冻结留出评测→`experiment.py`；S8案例核验与统计→`analyze.py`。
