# 算法、输入与训练目标

## 公开观察与风险

`arena/risk.py` 只接收公开观察，不接收环境对象、种子或隐藏地图。起点、公开钻石和已到达安全格均作为安全条件；已爆雷为已知雷且不从总雷数中删除。经典八邻域数字形成约束。先做零/满约束及集合相减推理，再把约束前沿拆成连通组件。

对于组件的兼容雷分配，按组件雷数计数；合并各组件后，用 `C(U, M-k)` 加权剩余 U 个无约束格，其中 M 是扣除已知雷后的全局剩余雷数，k 是组件中的雷数。分母是全部兼容分配的加权和，分子额外要求被查询格为雷。V1先验是在非起点、非钻石格均匀放置固定10雷；V2将公开角落安全区也排除，并分别固定40或99雷。推断读取公开总雷数和安全条件，不把10硬编码到大棋盘。没有筛选可达地图。

单组件超过23变量或深搜超过30000节点时，放弃此次完整模型计数，使用约束局部投影估计，明确标记 `approximate_cutoff`；其他完整计算标记 `exact_global_model_count`。近似值不是严格概率界限。已有24个4×4小盘与新增600个小图独立穷举对照测试；V1的5200正式局实际出现97次近似标记，全部保留。V2状态更大，其精确/近似次数单独统计，不能沿用该数值。

对超过81格的棋盘，冗余子集推导的预处理最多执行50000次比较，诊断为`closure_exhausted`和`closure_comparisons`；全部原始数字约束仍保留。预处理达到该预算本身不等于后验近似：若后续分量在23变量/30000节点预算内全部完整枚举，仍可输出精确计数；只有枚举超限才使用近似状态。这个预算用于控制大棋盘推理成本，不读取真值或删掉困难地图。

## B0、B1、B2

所有策略共享同一公开合法动作掩码。B0从合法动作中随机选择。未知雷不会因后台真值被屏蔽；已公开爆雷格按公开规则不可进入。

B1和B2都用Dijkstra计算到钻石的加性路线代价。进入格的代价为 `1 + 5p/max(0.03,1-p)`，已逻辑确认雷的格代价为10000。它是路径规划的启发式风险罚项，**不是路径存活概率**，没有把相关边缘安全概率相乘。等待额外加2的代价，仅影响选择成本，不改变V1的200步或V2的800/1600步上限。

B1最小化行动后到某钻石的路线代价 d，不使用对手位置、分数和存活信息。B2对仍存活的对手计算公开位置到同一资源的代价 o，并使用：

`cost = d + 0.7 max(0, d-o+0.5) - 1/(1+|d-o|)`

选择最小代价的动作和目标。对手已淘汰时竞争项为0。该式是本项目工程启发式，表达距离竞争，不声称准确预测对手内部目标，也未证明最优。

## V1的L与匹配消融

每个动作编码27个特征：目的格风险、是否已揭、是否等待、分数差、已用步数比例、资源数量、对手存活、目的格行列坐标（9项）；按坐标排序的最多3个资源各有动作后代价、当前代价、代价改善、对手到达代价、到达差、目的地是否为该钻石（每资源6项）。缺资源槽有明确占位值。

共享动作评分网络为 `fθ(x)=w₂ᵀ tanh(W₁x+b₁)+b₂`，隐藏宽度32，共929个参数。对五个动作的实际网络输出应用合法动作掩码，然后取最大logit。网页显示实际logit，不把启发式回退冒充学习；缺少权重直接报错。网络没有独立目标头，显示目标是动作后的路径归因，明确标注为**推断目标**。

训练是B2教师动作的监督模仿，损失为合法动作softmax交叉熵：

`J(θ) = -(1/N) Σ log softmax(mask(fθ(x_s,a)))[a_B2(s)]`

没有强化学习、奖励塑形或最优动作标签；终局胜负只是后续评测和训练图失败状态筛选依据。一次真实雷位也没有作为概率标签。Adam学习率0.002，batch256，初训45轮；从L_initial在训练图的输局状态和与B2动作分歧状态收集一次纠正数据，再对原样本与纠正样本合并训练20轮。每阶段固定预算内按验证集交叉熵最低保存检查点；不得用测试胜率挑权重。补训仍是监督学习，不声称自主发现策略。

`L_no_opponent`使用相同样本、标签、网络宽度、训练种子和45+20轮预算，移除**显式对手位置、得分和存活特征**：分数输入改为己方分数，对手距离、到达差及存活输入置零。共享已揭线索仍保留，因而仍可能反映双方过去行动的公共结果；不能称“排除对手造成的一切信息”。扰动对手位置、分数和存活后，其特征保持一致的测试已通过。

实现对应：S1观察与合法动作→`env.py`；S2约束风险→`risk.py`；S3动作/资源特征→`policies.prepare`；S4规则/网络评分→`policies.choose`；S5记录→`env.step`；S6模仿和补训→`learning.py`；S7冻结留出评测→`experiment.py`；S8案例核验与统计→`analyze.py`。

## V2专用模型与资源候选

`prepare_v2`支持16×16与30列×16行的矩形路径图。动作特征保留前27项的结构，但位置按宽高、距离按最大边长、分差和资源数按预设资源总数归一化；新增宽/30、高/30、雷密度、己方生命/3和对手生命/3，总计32维。其隐层48单元，结构32→48→1，共1633参数；`L_v2`加载`models/challenge_final.npz`，初训版本加载`challenge_initial.npz`。

B1/B2计算所有剩余资源的公开风险路线；网络只接收按当前位置路径/争夺代价排序的前三个，坐标用于稳定打破同值。候选预选是工程启发式，不是网络直接编码全部7/11资源，也不是独立学习的目标头。所显示目标依旧是对动作的路径归因。旧L权重用于V2时明确标注分布外，不能声称是V2训练结果。

V2冻结训练方案为B2-v2监督模仿、Adam学习率0.002、batch256、初训35轮和一次18轮补训，按验证交叉熵选权重。每个训练对局完整保存，只对送入特征训练的候选状态去重、最多等距选192条；纠正仍只来自训练图失败或教师动作分歧。它不产生最优标签，也不把单次雷位结果当作概率监督。真实训练完成量、选中轮次、完整评测和质量审计应读取独立V2日志，V1消融结论不能套用到V2。

## E：无教师动作标签的参数探索

`arena/exploration.py`提供与L_v2分开的CEM黑盒策略搜索。策略是八维公开特征的线性评分：目标格风险、是否已揭、等待、最近资源曼哈顿距离、最近资源风险路线、最佳资源距离领先量、是否到达资源及与存活对手的距离。非法动作仍只按公开规则屏蔽。它不使用B2动作作为标签，但使用手工风险与路径特征，所以不是从原始图像或无先验规则中自主发明策略，也不是PPO或神经网络训练。

冻结目标为终局胜1/平0.5/负0，加`0.25×(己方钻石−对方钻石)/7`。没有逐步奖励，也没有为“绕路、等候、转移”等预设行为加分。搜索分布采样候选系数，按完整训练对局目标选精英并更新分布；固定B1/B2与上一完整代的冻结训练优选策略构成对手池。训练可有公开随机探索，验证和测试采用冻结确定性策略。

协议将中级图分为6训练、2验证、4独立测试。初始策略及每完整代的训练优选候选在验证图上选最终权重，再单独测试初始/最终策略；测试结果不得回流选权重。绕路、等待、风险进入和目标切换只是日志判据，诊断目标仍由路径归因，不能当作独立目标头或网络意图。实际完成代数、局数、时间预算中断及确认结果以`data/exploration_v2`日志为准，不把计划4代当作已完成证据；稳定新行为必须有独立确认，不能只看系数变化或胜局片段。
