# 按批次继续训练与结果记录

当前夺宝学习路线为 B3 教师的监督模仿。继续实验不需要人工逐局打标签或外部 API；网页对打只运行已保存策略，不更新模型。每批训练需要独立的配置、权重、日志及结果文件。

## 扩充数据与三个独立初始化

`arena.training_batch` 固定当前 arena-v3.0 / survival-v1 规则及 40→48→1 网络。本批两种难度各用 36 张训练图、12 张验证图、20 张测试图，共 136 张基础图。训练集共有 144 局采集，验证集 48 局；标签是 B3 的公开信息决策，不能称为最优动作。每局最多均匀选择 192 条合格状态，完整轨迹仍保留。

三个候选从不同随机权重初始化，各训练 45 轮，共享同一批训练和验证数据；这是三个独立实验，不是连续在上一次权重上补训三次。每次按最低验证交叉熵保存检查点，再在测试前按相同验证指标提名一个候选。全部候选都报告，不能按测试胜率只留下最好的一次。本批没有纠偏阶段，也没有改动奖励函数或教师策略。

基础图及其镜像、旋转、换座、先手变化不能跨分区。可以指定旧实验私人清单进行排重。旧版本与新候选在相同测试图对 B2、B3 比赛，交换座位与先手。每个候选 320 局，旧 L3 基线另跑 320 局且三份报告共用，总计 1280 测试局；独立测试地图仍是 40 张。

## 运行

在仓库目录中执行，输出目录必须是新的空目录，私有目录必须在公开仓库和实验输出之外：

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
python -m arena.training_batch all --output ../training-runs/run-002 --private ../private-training/run-002
```

如持有旧实验的私人清单，可重复添加 `--exclude-manifest` 参数，清单只在可信实验程序中读取。全新公开克隆可以生成新地图复现方法；要逐数复现既有结果，需要相应私人清单。隐藏雷图和生成种子不得作为策略输入，也不能放进公开仓库。

进程中断后保留原目录，并依次使用 `collect`、`train`、`evaluate`、`audit` 阶段命令及相同 `--output`、`--private` 参数。已完成的采集和训练通过哈希核验后复用；未完成的产物移到本批 `incomplete_attempts` 保留。已完成的评测拒绝覆盖。完成训练后再开始留出评测，不以测试成绩调整轮数、种子、规则或地图。

## 每次训练的结果文件

每次正式训练都要单独交付一份可编辑 Word 和一份 PDF 结果报告，并保留原始 JSON；同批多次训练另外提供汇总。报告内容包括数据范围、训练配置、实际轮次与耗时、学习曲线、留出结果、失败和局限、权重哈希。不能只交付汇总而省略某一次较差结果。本入口自动保存下列机器可读记录，排版后的 Word/PDF 还需要生成并逐页检查；网页没有后台自动训练或定时任务。

| 文件 | 含义 |
|---|---|
| `protocol.json` | 运行前冻结的地图数量、训练预算、源码与基线哈希 |
| `models/L3_run01.npz` | 第一次独立训练的真实权重；另有 run02 和 run03 |
| `models/L3_run01_training.json` | 每一轮损失、模仿准确率、选中轮数、纯优化耗时和权重哈希 |
| `reports/L3_run01_result.json` | 该次训练、测试和旧 L3 配对比较；另有 run02 和 run03 |
| `selection_before_test.json` | 测试前的验证集提名，不表示已替换游戏默认模型 |
| `data/*_features.npz` | 可用于独立复训的公开特征、合法动作掩码与教师标签 |
| `data/*_transitions.jsonl.gz` | 完整公开行动、反馈和采样标记 |
| `evaluation/games.csv` | 全部测试局的输赢、钻石、生命、行动和耗时 |
| `evaluation/public_replays.jsonl.gz` | 全部测试局公开回放，包含失败、平局和超时 |
| `evaluation/paired_effects.json` | 按基础地图等权统计的旧模型差异与区间 |
| `integrity_audit.json` | 重放、特征重建、分区隔离及权重验证结果 |

每份结果报告应同时给出胜平负、钻石、剩余生命、踩雷及行动数。少行动可能来自早死，模仿准确率也不代表对战胜率。计时受机器与缓存影响，仅作运行记录，不用来判断游戏胜负。三个训练随机种子不能替代更多独立地图；多个对阵区间也不构成整体显著性检验。

本批候选不自动替换游戏模型。改进的判断以完整留出结果及其不确定性为依据，下降、无提升和超时均应保留。
