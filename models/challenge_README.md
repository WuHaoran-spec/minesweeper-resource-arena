# Challenge v2 模型

`challenge_initial.npz` 和 `challenge_final.npz` 是 arena-v2.0 中级/高级棋盘上的真实 CPU 监督模仿模型，独立于旧版 9×9 权重。网络按每个合法动作输入 32 个公开特征，经 48 个 tanh 隐藏单元输出一个 logit，共 1,633 个参数。

- `L_v2_initial` 加载初训权重：35 轮、1,295 次优化更新；验证交叉熵最优第 35 轮。
- `L_v2` 加载补训权重：在原训练图上完成一轮教师纠正，18 轮、972 次优化更新；验证交叉熵最优第 18 轮。
- 最终 SHA256：`24eb8b59771a014389c31371fffc37f09b0c040f842e3249acebba56990eb8e2`。

教师为 B2-v2 启发式。输入来自允许公开的观察，不包含隐藏雷位、生成种子或终局未来结果。最多 3 个资源槽按公开路线/竞争代价预先选出，这是人工特征设计，不是网络自主发现目标选择。教师动作标签不保证最优，模型不是无教师探索或强化学习；E 策略另有独立训练与评测记录。

训练数据、验证集、负结果、局长及复核范围见 [v2 实验报告](../docs/challenge_v2_experiments.md) 与 [数据卡](../data/challenge_v2/dataset_card.json)。逐轮损失、选中轮、时长和哈希见对应 `*_training.json`。自产合成轨迹和模型按本仓库 MIT 许可提供，无外部预训练权重、商业游戏数据或真人记录。

旧 `L`、`L_initial`、`L_no_opponent` 对应 v1 929 参数网络，文件保持原样；将旧 L 用于 v2 会明确标为分布外使用。
