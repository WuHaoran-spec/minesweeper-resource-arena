# L3 survival-v1 模型说明

`survival_v3_initial.npz` 与 `survival_v3_final.npz` 是实际 NumPy Adam 训练所得权重，不是启发式规则换名。结构为每动作共享的 40→48→1 tanh 打分器，共 2017 参数，环境公开合法掩码排除非法动作后选择最高分。输入中的路径、候选资源和历史特征仍由人工设计。

训练任务是模仿 B3 公开风险路径启发式，没有最优动作证明、真实玩家数据、工业现场数据、强化学习或自动涌现策略的声称。B3 的风险权重随剩余生命从 8 增到 18、72，加上公开近24次位置的重复/折返/等待代价；它不保证每一步安全或更高胜率。

数据使用 arena-v3.0 / survival-v1，中级16×16和专家30列×16行，每档12训练、4验证、6测试基础图。镜像、换座、先手及回放不能跨集合。初训5597状态，验证1761状态；一轮训练图纠偏2920状态，合并8517状态。初训35轮770次更新、纠偏18轮612次更新；各自按验证交叉熵选择第35/18轮。没有用测试对战挑选权重。

加载：`arena.policies.choose(public_observation, 'L3')`。权重缺失会明确报错，不能静默换成 B3。旧规则或缺少公开历史会标记分布外使用。推断输入不含种子、隐藏雷位或未来结果；真值仅由仓库外可信训练/评测程序保存。

完整训练记录见同目录 `survival_v3_*_training.json`；留出对战、生存/钻石/效率取舍和审计见 `docs/survival_v3.md` 与 `data/survival_v3/`。验证模仿准确率不是胜率，也不等同于更优或更安全。

公开数据复训：将 `ARENA_OUTPUT_DIR` 设为独立输出目录，运行 `python -m arena.survival_training refit-public`。该入口只读仓库中的特征NPZ，不读取私有地图种子，且拒绝覆盖仓库候选模型。已实际独立重训一次，两份权重SHA均与上表相同；记录见 `data/survival_v3/public_refit_verification.json`。这证明本机复现，不是跨优化器种子稳定性，其他数值库可能产生浮点舍入差异。

权重和自行合成的数据按项目 MIT 许可提供。旧 L/L_v2/E 权重未覆盖。
